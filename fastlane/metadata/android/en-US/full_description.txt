Password and passkey manager that is compatible with ZX2C4's Pass commandline application: Credentials are stored in text files which are encrypted with OpenPGP.

<strong>Features:</strong><br>
• Clone from and sync with a remote Pass Git repository<br>
• View, add, and edit password entries.<br>
• Supports time-based one-time passwords (TOTP) for two-step authentication<br>
• Automatically fill and save credentials in apps and supported browsers<br>
• Respond to passkey creation and authentication requests from browsers and native apps<br>
